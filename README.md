# GRS 1915+105 Kinematic Analysis Pipelines

![Python](https://img.shields.io/badge/python-3.8+-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

This repository contains the primary Python pipelines for modeling and plotting the astrometric and flux data of the **GRS 1915+105** microquasar jets. It provides tools for robust kinematic modeling, Markov Chain Monte Carlo (MCMC) parameter estimation, and publication-ready data visualization.

---

## 🚀 Overview

The codebase is split into two primary methodologies for analyzing jet kinematics:

1. **Absolute Kinematics (`src/pipeline_absolute_kinematics_with_limits.py`)**  
   Models jet kinematics based on absolute celestial coordinates (Right Ascension and Declination) relative to a fixed catalog position.  
   *Key Features:*
   * Calculates the global astrometric offset of the central core.
   * Fits ballistic/polynomial kinematic models using **MCMC sampling** (via `emcee`) directly to the absolute RA/Dec coordinates.
   * Analyzes and models the flux evolution over time to produce early-epoch extrapolations.

2. **Relative Kinematics (`archive/pipeline_relative_kinematics.py`)**  
   Models kinematics based on the relative angular separation between the moving lobes and the observed core position at each individual epoch.  
   *Key Features:*
   * Highly robust against epoch-to-epoch absolute referencing errors.
   * Projects separations into parallel and perpendicular components along the jet axis.
   * Tracks position angle (PA) evolution over time to account for jet precession.

## 📂 Directory Structure

```text
├── src/                # Core analysis pipelines and plotting scripts
├── archive/            # Older scripts (relative kinematics, standalone plotting)
├── alpha/              # Spectral index fitting (get_alpha.py)
├── data/               # Output text and NumPy data generated by the pipelines
│   ├── absolute_kinematics/  # Old absolute pipeline: per-model reports and plot data
│   └── peel_regions/         # Peel regions, core-only clean masks, peel diagnostics
├── docs/               # Model guide, change log and paper draft (main.tex)
├── figures/            # Generated plots
│   ├── paper/                # Figures used in docs/main.tex
│   ├── absolute_models/      # Old absolute pipeline, models 1-6
│   ├── kinematics/           # Kinematics, PA and flux plots
│   ├── peel/                 # Peeling and upper-limit diagnostics
│   └── spectral/             # Spectral index plots
├── FITS/               # MeerKAT images (not in git)
│   ├── pcalmask/             # Campaign MFS pbcor images, one per epoch
│   └── peel/                 # Post-peel images and pre-peel models (ep1_run1, ep1_run2, ep3, ep4)
├── masks/              # Original 3GC clean masks (epoch1, epoch3, epoch4; not in git)
├── S-band-fits/        # 2D Gaussian fitting results for S-band images
├── lc/                 # Lightcurve data and dedicated plotting scripts
├── scratch/            # Throwaway test scripts and backups
│   ├── draft_backups/        # Copies of the draft before edits
│   ├── before_edits/         # Copies of scripts and tables before edits
│   ├── kinematics_reports/   # One-off kinematics reports cited in draft notes
│   └── peel/                 # Peel diagnostics runs
├── scripts_txt/        # .txt mirror of all scripts (kept in sync by src/sync_txt_scripts.py)
├── requirements.txt    # Python dependencies for the project
└── README.md           # Project documentation
```

## 🛠️ Installation & Requirements

Ensure you have Python 3.8+ installed. You can install the required dependencies using `pip`:

```bash
git clone https://github.com/yourusername/GRS1915-Kinematics.git
cd GRS1915-Kinematics
pip install -r requirements.txt
```

**Main Dependencies:**
- `numpy`
- `scipy`
- `matplotlib`
- `emcee` (for MCMC sampling)
- `corner` (for posterior visualizations)

---

## 💻 Usage

To run the pipelines, execute the scripts from the **repository root directory**. This ensures all relative paths for saving figures and data resolve correctly.

```bash
# Run the absolute kinematics pipeline
python src/pipeline_absolute_kinematics_with_limits.py

# Run all kinematic models and compile the comparison
python src/run_and_compile_all_models.py
```

Outputs will be automatically saved to the `figures/` and `data/` directories.

---

## 📊 Outputs & Visualizations

The pipelines automatically generate high-quality `.png` figures to visualize the data and the MCMC fits. Examples of generated figures include:

- **Astrometric Tracks**: 2D absolute tracks of the ejecta on the sky (`figures/ra_dec_plot.png`).
- **Flux Evolution**: Flux over time with extrapolated predictions (`figures/flux_evolution_with_extrap.png`).
- **Parameter Posteriors**: Corner plots displaying the marginalized posterior distributions from the MCMC sampling (`figures/absolute_corner_plot.png`).
- **Separation vs. Time**: 1D relative displacement models (`figures/absolute_parallel_perp_fit_plot.png`).
